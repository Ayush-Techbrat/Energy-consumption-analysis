# Energy Consumption Analysis Using Python and Pandas

## Project Overview
This project analyzes household electricity consumption data using Python and Pandas.

## Dataset
Household Electric Power Consumption dataset.

## Tools Used
- Python
- Pandas
- Matplotlib
- Jupyter Notebook
- VS Code

## Key Analysis
- Daily electricity consumption
- Monthly consumption patterns
- Hourly consumption trends
- Weekday consumption patterns
- Missing value analysis
- Statistical summaries

## Key Findings
- Average active power consumption is approximately 1.09.
- Consumption is highest around 8 PM.
- August has the lowest average monthly consumption.

## Project Files
- energy.ipynb: Analysis and visualizations
- daily_consumption.png: Saved chart
- household_power_consumption.txt: Dataset

## How to Run
1. Install Python.
2. Install pandas and matplotlib.
3. Open energy.ipynb in VS Code.
4. Run the notebook cells.
