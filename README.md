# Energy Consumption Analysis Using Python and Pandas

## Project Overview
This project explores household electricity consumption data using Python, Pandas, and Matplotlib to identify daily, monthly, hourly, and weekday consumption patterns.

## Dataset
Household Electric Power Consumption dataset from the UCI Machine Learning Repository.

The dataset is not included in this repository. Download it separately and place `household_power_consumption.txt` in the project folder.

## Tools Used
- Python
- Pandas
- Matplotlib
- Jupyter Notebook
- VS Code
- Git and GitHub

## Project Work
- Loaded and explored household electricity consumption data.
- Identified and handled missing-value markers.
- Converted measurement columns to numeric data types.
- Created datetime-based features.
- Analyzed daily and monthly consumption patterns.
- Compared consumption by hour and day of the week.
- Generated visualizations and statistical summaries.

## Project Files
- `energy.ipynb` — data analysis and visualizations.
- `daily_consumption.png` — saved consumption chart.
- `.gitignore` — excludes the local dataset and ZIP files.

## How to Run
1. Install Python.
2. Install the required libraries: `pandas` and `matplotlib`.
3. Download the dataset and place the text file in the project folder.
4. Open `energy.ipynb` in VS Code or Jupyter Notebook.
5. Run the notebook cells.
